# Database Documentation

## Main Tables

### Users & Authentication
- `users` - Main user accounts
- `user_profiles` - User personal information
- `roles` & `permissions` - RBAC system

### Student Information
- `students` - Student preferences and details
- `education_records` - Academic history
- `test_scores` - Standardized test scores
- `achievements` - Extracurricular activities

### Applications
- `applications` - Student applications to programs
- `application_stages` - Workflow stages
- `application_statuses` - Status tracking

### Universities & Programs
- `universities` - University information
- `programs` - Academic programs
- `program_requirements` - Admission requirements

### Supporting Tables
- `attachments` - File uploads system
- `recommendations` - Recommendation letters
- `notifications` - User notifications
- `student_visas` - Visa tracking
